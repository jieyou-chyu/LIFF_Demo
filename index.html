還缺 LIFF ID

config.js 裡的 LIFF_ID 是空的。這一頁要能登入， 必須先到 LINE Developers Console 建一個 LIFF app，再把它的 LIFF ID 填進來。

  1. LINE Developers Console → 你的 LINE Login channel → LIFF 分頁 → Add L
  2. Endpoint URL 填 https://<你的帳號>.github.io/<repo>/ （必須 HTTPS、不能是 localhost，且要覆蓋這一頁的路徑）
  3. Scope 勾 profile 與 openid（少了就拿不到名字或 ID token）
  4. Size 選 Full（或 Tall），建立後複製 LIFF ID（格式 1234567890-AbCdEfgh）
  5. 把 LIFF ID 填進 config.js，commit 後等 Pages 重新部署

臨時測試也可以直接在網址後面加 ?liffId=你的LIFF_ID，不用改檔案 （該網址仍必須在 Endpoint URL 之下）。
